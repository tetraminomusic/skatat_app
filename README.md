# Skatat' for <i>MAC OS</i> 
## by tetramino

Консольная приложуха на питоне, которая перехватывает скриншоты, парсит текст и отправляет запрос Gemini, и выводит ответ либо в уведы мака (через скрипты), либо вручную печатает текст, имитируя человеческую печать.

## Разрешения в macOS (Обязательно)
При первом запуске скрипта Mac попросит права. Нужно разрешить:
1. **Универсальный доступ (Accessibility):** `Системные настройки` -> `Конфиденциальность и безопасность` -> `Универсальный доступ` -> Включить ваш Терминал / iTerm / VS Code.
2. **Запись экрана (Screen Recording):** В том же меню разрешить терминалу делать скриншоты.

## Установка
```bash
git clone <ссылка-на-репозиторий>
cd rubezh
chmod +x install_env.sh run.sh
./run.sh
```

Добавьте API-ключ в систему:
```bash
echo 'export GEMINI_API_KEY="ВАШ_КЛЮЧ"' >> ~/.zshrc
source ~/.zshrc
```

## Запуск
```bash
./run.sh
```

## Горячие клавиши (Англ. раскладка)
* **`Cmd + Shift + 3`** — Ответ на тест (всплывающее уведомление).
* **`Cmd + Shift + 2`** — Автопечать кода (генерация + симуляция набора).
* **`Cmd + Shift + 1`** — Экстренная остановка печати.
